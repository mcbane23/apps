# apps

APK-ovi mojih aplikacija. Kod je u posebnim (privatnim) repoima; ovde su samo izdanja.

Svaka aplikacija ima svoja izdanja po imenu taga:

- **IPTV plejer**: `iptv-player-dev` (poslednji build sa main-a, aplikacija se iz njega sama ažurira)
- **Roditeljska kontrola (Parental Control)**: `parental-control` (poslednje izdanje, aplikacija se iz njega sama ažurira)
